# F1与全球赛车编辑晨报｜2026-09-23

> 统计窗口：北京时间 2026-09-22 07:00—2026-09-23 07:00。当前赛事阶段：阿塞拜疆大奖赛赛前；本周赛程因阿塞拜疆9月27日纪念日整体提前一天，F1周四练习、周五排位、周六正赛。

## 1. 今日30秒总览

- **伊萨克·哈贾尔（Isack Hadjar）确认复出。** 红牛官方确认其手腕伤势恢复，将从巴库周末重新搭档马克斯·维斯塔潘；利亚姆·劳森回到Racing Bulls，角田裕毅回归储备车手角色。这结束了红牛连续三站的临时阵容安排。
- **巴库轮胎选择发生明显变化。** 倍耐力本周提供C3硬、C4中、C5软，相比2025年包含C6的选择整体硬一级；每位车手基础配额为2套硬、3套中、8套软。
- **FIA确认巴库设两段直线模式区域。** 在2026主动空气动力学规则下，巴库超长直道让直线模式效率、尾翼方案和阻力水平成为周末技术重点。
- **凯迪拉克进入首个巴库周末。** 车队赛前信息显示将带来小幅空气动力学升级；塞尔吉奥·佩雷兹赛车将使用新版法拉利动力单元。
- **耐力赛方面，富士6小时进入比赛周。** Alpine确认富士站两台A424均采用双车手阵容，安东尼奥·费利克斯·达科斯塔和弗雷德里克·马科维奇本周不参赛。
- **IMSA：塞巴斯蒂安·布尔代加入DragonSpeed。** 车队将在小勒芒回到GTD PRO，布尔代与贾科莫·阿尔托埃、卡斯珀·史蒂文森驾驶科尔维特Z06 GT3.R。

## 2. F1重点新闻

### 哈贾尔确认在巴库复出

**发布时间：** 9月22日 16:15（北京时间）  
**性质：** 官方确认  
**可信度：** 极高  

红牛确认伊萨克·哈贾尔（Isack Hadjar）已从夏休期间训练导致的手腕伤势中恢复，将参加阿塞拜疆大奖赛。他此前连续缺席荷兰、意大利和西班牙三站，期间利亚姆·劳森（Liam Lawson）代替他驾驶红牛，角田裕毅（Yuki Tsunoda）则临时进入Racing Bulls。随着哈贾尔回归，劳森返回Racing Bulls，角田恢复储备车手职责。

**为什么重要：** 红牛终于恢复原定2026阵容；巴库又是低下压力、高极速且墙体距离极近的街道赛，哈贾尔伤后首战的身体状态和重新建立比赛节奏值得重点观察。

来源：[Formula 1｜Hadjar to make racing return with Red Bull at Azerbaijan GP](https://www.formula1.com/en/latest/article/hadjar-to-make-racing-return-with-red-bull-at-azerbaijan-gp.1ddPnUSDEze0V9MCiQ9d2U)；[Autosport｜Hadjar set to make Red Bull return at Azerbaijan GP](https://www.autosport.com/f1/news/hadjar-to-make-red-bull-return-in-baku/10857880/)

### 倍耐力巴库配胎：C3/C4/C5

**发布时间：** 9月22日 17:18（北京时间）  
**性质：** 官方信息  
**可信度：** 极高

本周使用C3硬胎、C4中性胎、C5软胎。2025年巴库的选择还包含C6，因此2026方案整体向更硬方向移动一级。每名车手获得2套硬、3套中、8套软；进入Q3者另有一套软胎预留。干地正赛仍要求使用至少两种不同光头胎配方。

**为什么重要：** 巴库兼具长直道、低速城区和强烈制动，较硬的选择可能扩大长距离管理窗口，也会影响暖胎和排位单圈准备。

来源：[Formula 1｜What tyres will the teams and drivers have for the 2026 Azerbaijan Grand Prix?](https://www.formula1.com/en/latest/article/what-tyres-will-the-teams-and-drivers-have-for-the-2026-azerbaijan-grand-prix.1UFiasleBnLs9s0hyRCpS0)

### FIA确认两段直线模式区域

**发布时间：** 9月22日  
**性质：** FIA赛道设置经媒体报道  
**可信度：** 高

FIA确认巴库本周设置两段直线模式区域。2026赛车主动空气动力学在巴库的价值尤其突出：赛道拥有极长全油门路段，但老城区又要求机械抓地和低速稳定性，因此各队低阻力尾翼概念与直线模式效率会成为重要技术观察点。

来源：[PlanetF1｜FIA makes key Baku decision for Azerbaijan Grand Prix](https://www.planetf1.com/news/fia-azerbaijan-grand-prix-2026-baku-active-aero)；[The Race｜How each active F1 rear wing concept works](https://www.the-race.com/formula-1/how-each-active-f1-rear-wing-concept-works-gary-anderson-explains/)

## 10. 赛事阶段专题：巴库赛前

本周最容易出错的是**日期**：阿塞拜疆大奖赛不是通常的周五—周日，而是周四—周六。北京时间F1核心节点为：9月24日16:30 FP1、20:00 FP2；9月25日16:30 FP3、20:00排位；9月26日19:00正赛。

技术上建议重点观察三件事：第一，主动空气动力学直线模式在两段区域的速度收益以及不同尾翼概念差异；第二，C3/C4/C5较2025更硬的轮胎组合是否带来暖胎问题；第三，哈贾尔伤愈后的长距离稳定性和高负荷转向表现。巴库的长直道与老城区低速段对赛车要求冲突明显，因此练习赛的尾速、慢弯牵引和轮胎温度应结合看，而不能只看单圈排名。
